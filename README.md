## Featured Project

### [Sign Language to Speech Conversion](https://github.com/RhythmusByte/Sign-Language-to-Speech)

A real-time American Sign Language recognition system designed to translate hand gestures into speech, helping bridge communication barriers.

- **Recognition:** CNN-based hand gesture classification
- **Real-time processing:** OpenCV
- **Speech output:** Converts recognized gestures into spoken output
- **Stack:** Python, CNN, OpenCV, Keras
